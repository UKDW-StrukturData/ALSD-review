# Soal 02 — Percabangan

## Tujuan
Melatih penggunaan struktur percabangan (`if-elif-else` dan `match-case`) di Python.

## Soal
Buatlah program Python yang:

1. Menggunakan `nilai_akhir` dari **Soal 01** (boleh input manual/hardcode untuk soal ini).
2. Menentukan **grade** mahasiswa berdasarkan aturan berikut, menggunakan `if-elif-else` atau `match`:

   | Rentang Nilai | Grade |
   |---|---|
   | 85 - 100 | A |
   | 70 - 84  | B |
   | 60 - 69  | C |
   | 50 - 59  | D |
   | < 50     | E |

3. Cetak hasil dalam format: 

## Contoh Output
```
Nilai 78.5 -> Grade B
```
